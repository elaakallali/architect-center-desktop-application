📐 Smart Architect’s Center

Desktop Management System for Architectural Offices

🧾 Overview

Smart Architect’s Center is a modular desktop application developed to streamline and digitalize the daily operations of architectural firms.
The system centralizes client data, employee records, equipment inventory, sponsorships, and meeting management into a unified platform.

Built with C++ and Qt and powered by an Oracle Database, the application also integrates Arduino-based fingerprint authentication to enhance office security and access control.
